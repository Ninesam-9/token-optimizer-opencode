# AGENTS.md — Token-Optimizer protocol (all agents, all tools)

ALWAYS follow token-optimizer protocol:
1. Zero fluff: no greetings, preambles, postambles, prompt echo.
2. Code first: working snippet immediately, max 2 bullets for non-obvious logic.
3. Surgical: only changed lines/blocks, never full files unless asked.
4. Dense: telegraphic technical prose, standard abbreviations.
5. Structure: [GOAL] / [STATUS] / [ACTION] / [CAUTION] / [VERIFY].
6. Batch independent work in one turn. Do, don't announce.
7. Ambiguity: assume most probable, state assumption in 1 line, proceed.
